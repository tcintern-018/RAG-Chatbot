This project is a simple AI Chatbot built with React with a clean, responsive, and user-friendly chat interface. The frontend was developed using React components and state management to handle user messages, chat history, loading states, and AI responses dynamically. A chat input allows users to enter their questions, which are sent to the backend/API for processing, and the generated response is then displayed in the conversation. The interface also includes separate styling for user and AI messages, a responsive layout, and a smooth conversational experience. The project demonstrates how React can be used to build an interactive AI-powered application while keeping the frontend modular, reusable, and easy to extend with additional AI models or backend services in the future.

This project is an AI-powered RAG (Retrieval-Augmented Generation) Chatbot built to answer questions from custom knowledge documents. The knowledge base includes documents related to Artificial Intelligence, Deep Learning, RAG, and the RAG chatbot project itself. The documents are processed using text splitting and chunking, then converted into vector representations using Google Gemini Embeddings and stored in ChromaDB for efficient similarity-based retrieval. For generating responses, the project uses the Google Gemini model (Gemini 1.5 Flash), which receives the user's query along with the most relevant retrieved document context and generates a grounded response. The project demonstrates the complete RAG workflow, including document loading, text splitting, embeddings, vector storage, retrieval, context injection, prompt templates, and Gemini-based response generation, with a simple chatbot interface for interacting with the knowledge base.
